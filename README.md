# JERA – JugendERA e. V.

**Dein Leben. Dein Weg. Deine Möglichkeiten.**

JERA ist ein Angebot des gemeinnützigen Vereins JugendERA e. V. mit Sitz in Münster.

Wir begleiten junge Menschen dabei, sich selbst besser kennenzulernen, persönliche Herausforderungen zu reflektieren und ihren eigenen Weg zu gestalten.

Im Mittelpunkt stehen individuelle Begleitung, Selbstvertrauen, emotionale Stabilität, persönliche Entwicklung und selbstbestimmte Entscheidungen.

## Unsere Webseite

**[www.be-jera.org](https://www.be-jera.org/)**

Die Webseite informiert über unsere Haltung, unsere Angebote und den Ablauf einer persönlichen Begleitung. Sie ermöglicht außerdem einen unverbindlichen Selbstcheck sowie die Kontaktaufnahme für ein kostenloses Kennenlerngespräch.

## Technische Umsetzung

Die Webseite wird als statische Website über GitHub Pages veröffentlicht.

- HTML, CSS und JavaScript
- Responsives Design für Smartphone, Tablet und Desktop
- Eigene Domain mit HTTPS
- Suchmaschinenoptimierung und strukturierte Daten
- Interaktiver Selbstcheck

## Über JugendERA e. V.

JugendERA e. V. ist ein gemeinnütziger Verein mit Sitz in Münster.
